# NUR News

Production-ready news site built with Next.js 14, Sanity CMS, and Tailwind CSS.

## Quick Start

```bash
npm install
cp .env.example .env.local
# Fill in your Sanity credentials
npm run dev
```

## Deploy to Vercel

```bash
npx vercel --prod
```

## Sanity Studio

```bash
cd sanity
npm install -g @sanity/cli
sanity login
sanity deploy
```
